# 🎉 Birthday Surprise Website

An interactive, animated birthday surprise website built with modern frontend technologies. This project delivers a magical storytelling experience through multiple animated scenes, including a gift opening, birthday wishes, cake celebration, fireworks, and a heartfelt ending.

🔗 **Live Demo:** https://birthday-surprise-fklyowqtm-salih-hayat-s-projects.vercel.app

---

## ✨ Features

- 🌙 Beautiful animated night sky
- ⭐ Twinkling stars and floating clouds
- 🌠 Random shooting stars
- 🎁 Interactive gift opening animation
- 💖 Animated birthday message
- ✨ Magical "Make a Wish" scene
- 🎂 Birthday cake with candle blow interaction
- 🎆 Fireworks celebration
- ❤️ Beautiful ending screen
- 📱 Fully responsive design
- ⚡ Smooth GSAP animations
- 🎨 Modern glassmorphism UI

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- GSAP (GreenSock Animation Platform)
- Vite

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/salih-x-tech/YOUR_REPOSITORY_NAME.git
```

Go to the project folder

```bash
cd YOUR_REPOSITORY_NAME
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
